# Changelog

All notable changes, newest first. Versions follow `MAJOR.MINOR.PATCH`:
bug fix → `1.0.1`, new feature → `1.1.0`, big change → `2.0.0`.

## 1.0.0 — 2026-10-07

First release.

- Reading view: themes (Auto, Journal, Paper, Midnight, Slate, Sepia, Navy, KG),
  fonts, text size, page width, numbered headings, outline sidebar, word count.
- Research writing: math (KaTeX), callouts, footnotes, numbered figures and
  tables, code colors with copy buttons, action items, @mentions, meeting
  header from front matter.
- Present mode: slides from `---` or headings, auto-fit, full screen, keys.
- Talk timer: 7:00 by default, 1鈴/2鈴/3鈴 bells that follow the talk length,
  warning colors, size and position options.
- Presenter list: announces the next presenter automatically, `]` / `[` to
  move through the list, built-in voice (.mp4) or your own audio file.
